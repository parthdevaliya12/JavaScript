# FRAME. — Photography Discovery

A modern, responsive photography search application powered by the Unsplash API.

### ✨ Features
- Search photos by keywords
- Responsive gallery
- Download photos
- Load more results
- Redux Toolkit state management
- Modern UI with Tailwind CSS

### 🛠️ Tech Stack
React.js · Vite · JavaScript · Tailwind CSS · Redux Toolkit · Axios · Unsplash API

### 🚀 Installation

```bash
git clone YOUR_REPOSITORY_URL
cd FRAME
npm install
```

Create a `.env` file in the root directory:

```env
VITE_UNSPLASH_API=your_unsplash_access_key
```

Start the development server:

```bash
npm run dev
```

### 🌐 Build

```bash
npm run build
```
